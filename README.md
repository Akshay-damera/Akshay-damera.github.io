# Sai Akshay Damera Portfolio

A responsive personal portfolio website designed for GitHub Pages.

## Files

- `index.html` — portfolio content
- `style.css` — visual design
- `script.js` — navigation and scroll animations
- `assets/Akshay_Resume.pdf` — resume linked from the hero section

## Before publishing

Open `index.html` and replace:

```html
<a href="#" title="Replace this link with your exact LinkedIn profile URL">
```

with your actual LinkedIn URL, for example:

```html
<a href="https://www.linkedin.com/in/YOUR-USERNAME/" target="_blank" rel="noopener">
```

Also add GitHub links to individual projects later when the repositories are ready.

## Publish on GitHub Pages

1. Sign in to GitHub.
2. Create a new public repository named exactly:
   `Akshaydamera30.github.io`
3. Upload all files from this folder to the repository root.
4. Commit the files.
5. Go to **Settings → Pages**.
6. Under **Build and deployment**, choose **Deploy from a branch**.
7. Select the `main` branch and `/ (root)`, then save.
8. Your website should be available at:
   `https://Akshaydamera30.github.io/`

If you choose a different GitHub username, the repository name and URL should use that username instead.

## Local preview

Double-click `index.html`, or use VS Code Live Server.
